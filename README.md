# TeLIphone

Контрольная работа №1 по теме «HTML и CSS: разработка многостраничного сайта».

TeLIphone — учебный макет магазина актуальных моделей iPhone. Сайт сделан на HTML и CSS без JavaScript и серверной части.

## Страницы сайта

- index.html — главная страница, преимущества и популярные товары.
- catalog.html — каталог трёх моделей iPhone.
- product.html — описание iPhone 18 Pro и таблица характеристик.
- order.html — демонстрационная форма заявки.
- contacts.html — контактная информация.

## Технологии

Используются семантический HTML, один общий файл стилей css/style.css, CSS-переменные, Flexbox, CSS Grid, состояния hover и focus-visible, базовое БЭМ-именование классов и CSS-модальное окно.

## Изображения

Фотографии товаров находятся в папке images и подключены к главной странице, каталогу и странице iPhone 18 Pro.

## Как открыть сайт

Откройте index.html в браузере. Навигация между страницами работает через обычные ссылки.

## Форма

Форма показывает HTML-поля и встроенную проверку браузера. Она не отправляет данные на сервер. Не вводите реальные личные данные.
